# 内容导出

本模块为 Android/iOS 的回答、文章、问题描述、想法和日报提供统一导出入口。更多菜单只传内容类型、ID 和账号会话版本；进入导出页后重新获取正文。问题入口导出问题描述，回答入口导出所选回答，不隐式合并问题下的其他回答。当前不导出评论、附件原始 HTML、视频文件或互动接口数据，Web 暂不支持。

## 格式与交互

| 格式 | 产物 | 图片与排版 |
| --- | --- | --- |
| Markdown | `.md` | 保留公开远程图片链接；需要网络才能查看对应图片 |
| Markdown + 离线图片 | `.zip` | 正文 `.md` 与 `assets/` 相对目录；可整体解压后阅读 |
| HTML | 单个 `.html` | 可用图片和 KaTeX 字体内嵌，无需应用运行时 |
| PDF | `.pdf` | `expo-print` 按 A4 打印静态 HTML，采用打印分页样式 |
| 长图 | 优先一张完整 `.png` | 等待字体与图片就绪后分段截图，再无缝合并；超长内容按安全尺寸合成少量图片 |

保留标题、作者、可用的发布时间/更新时间和原文链接。正文或续页不完整时明确显示“部分内容”，用户确认后才能生成；文件自身保留完整性说明。资源准备失败时暂停生成，允许“重新准备”或“继续缺图导出”，缺图使用可见占位说明，不标记为完整离线内容。外链会清理已知跟踪参数，并保留可确认的正文标识；其余查询参数无法安全处理时，保留链接文字而不生成可能指向错误页面的链接。

HTML、PDF 和长图可选择包含正文图片以及采用阅读排版设置；缺少 LaTeX 的公式图片仍作为必要正文资源准备。公式有 LaTeX 时使用静态 KaTeX，不能解析时显示源码；较宽公式附可换行源码，打印时以源码避免裁切。复杂 Markdown 表格使用静态 HTML 保留合并单元格，兼容性取决于阅读器。视频和交互卡片保留静态说明、封面与公开来源链接。

Android“保存到文件”通过 Storage Access Framework 选择目录。iOS 通过系统分享面板提供“存储到文件”，只能确认面板已打开，不能确认用户已保存。多图分享打包为一个 ZIP；保存文件保留各张 PNG；“全部保存到相册”按顺序保存各张图，只请求照片写入权限。权限拒绝或中途失败会提示，用户可改用保存文件/分享；已成功写入外部目录或相册的部分文件可能仍保留。

## 模块边界

| 文件 | 责任 |
| --- | --- |
| `entry.ts`、`ContentExportScreen.tsx` | 菜单入口、会话身份、格式与选项、预览和保存交互 |
| `resolveSource.ts` | 获取完整可访问正文、回答续页、元数据与完整性判断 |
| `types.ts`、`errors.ts` | 来源、任务上下文、进度、产物类型和可展示的固定错误 |
| `assets.ts` | 遍历语义文档全部资源，限额下载/校验、data URI 与 Markdown 资源映射 |
| `safeUrl.ts` | 公开链接与图片 URL 筛选、敏感参数清理、准备后资产路径校验 |
| `serializeShared.ts`、`serializeMarkdown.ts`、`serializeHtml.ts` | 静态序列化、格式/脚注/表格/公式/来源说明 |
| `files.ts`、`ioShared.ts` | 独立缓存目录、受限文件名、ZIP、PDF、保存/分享、取消与错误清理 |
| `imagePagination.ts`、`ImageExportRenderer.tsx` | 安全分段、隔离 WebView 测量、逐段截图与临时图释放 |
| `pngStitch.ts` | 有界解码 PNG 扫描行、按顺序无损纵向合并、超长内容自动分组 |
| `useContentExport.ts` | 任务状态、缺图确认、重试、账号隔离、迟到结果丢弃 |

业务代码仅从 `@/features/rich-content` 获取统一文档、解析与排版能力。不会截图已有阅读页面，也不会直接导出其 WebView 运行时 HTML。导出解析与资源收集覆盖正文/行内图片、无 LaTeX 公式图、表格、嵌套列表/引用、脚注和卡片/视频封面，不能替换成画廊图片收集逻辑。

## 资源与安全限制

- 资源至多 120 个（规范 URL 去重），单资源至多 8 MiB，流式读取总计至多 32 MiB；至多 3 个请求并发，每个请求超时 15 秒。已内嵌的 data 图片同样计费并校验，不能绕过限额。
- 图片使用独立 `expo/fetch`，显式 `credentials: 'omit'`、`redirect: 'error'`；不调用认证 Axios、不携带 Cookie、X-ZSE 或完整请求配置。拒绝私网/IP、登录/API、本地路径、不明确的图片身份查询及不安全协议。网址参数策略由 `safeUrl.ts` 统一维护。
- 仅打包实际字节头匹配的 PNG/JPEG/GIF/WebP；不接受资源中的 SVG/HTML 或可执行内容。无法获取的资源产生不含原始 URL/异常的固定警告；超限与取消终止任务。
- 输出字节上限为 64 MiB。Markdown ZIP 仅允许模块生成的 `assets/asset-N.ext` 路径；文件名过滤分隔符、控制字符与保留名称，长度至多 64 个 Unicode 字符。
- PDF 只接收已嵌入资源的静态 HTML，拒绝脚本、外部样式、iframe 等加载入口；允许 KaTeX 生成的静态 SVG 与内嵌字体。原生打印最长等待 60 秒，不支持原生取消时忽略并清理迟到的 PDF。
- 回答正文续页至多 100 页；触及边界保留已获取正文并标注部分内容，不把缺失正文标为完整。
- 长图正文测量高度至多 200,000 CSS px，至多 120 个截图分段；每段使用有限屏幕尺寸表面，实际像素宽度不超过 1080 px、高度不超过 2000 px（iOS 参数按屏幕倍率换算）。PNG 按扫描行解码和重新压缩，逐组写入文件，不分配完整长图的 RGBA 位图；普通内容合成单个 PNG，单张最多 16,000 px 高、1600 万像素，超限时沿已有安全分段边界合成下一张，不缩小正文或丢弃内容。无法找到安全截图间隙时明确失败，提示改用 HTML/PDF。实际 WebView 排版、内存和截图效果仍需真机验证。

## 生命周期

每个任务固定内容身份及 `sessionVersion`，通过 `AbortSignal` 和 `assertActive` 在异步读写前后检查。账号切换、取消、页面退出或新任务使旧结果失效；不能把迟到正文、资源或文件交给后续账号。

iOS 截图模块返回的绝对路径在文件读取边界转换为 `file://` URI；释放截图时仍使用原始路径。

文件放在 `cache/exports/job-<id>/`，文件名和目录不包含账号身份。重新生成、退出与失败清理任务目录，截图源文件由截图模块释放；生成 PDF 后删除原生打印临时文件。启动导出模块时清理超过 24 小时的非活跃旧任务目录，作为进程中断后的补救。缓存不属于长期文档库，保存/分享前不能提前删除；已交给系统的保存/分享结果无法通过取消任务撤回。

文件生成结束后再次验证任务；过期文件删除，不展示给新会话。仅 `ContentExportError` 及其子类允许将明确撰写的错误文案展示给用户，其他异常统一转固定提示，不输出底层网络、WebView 或原生异常。

## 开发与验证

```bash
npm ci
npm test -- tests/contentExport --runInBand
npm run analyze:rich-content
npm test -- src/features/rich-content/tests --runInBand
npm run check
```

新增/更新 `expo-print`、`react-native-view-shot`、原生权限或相关 config plugin 后：

```bash
npx expo prebuild --platform android --no-install
npx expo prebuild --platform ios --no-install
```

重新编译安装 Development Build，再验收以下矩阵。旧原生包会提示对应模块不可用，Fast Refresh 不能替代重编译；`android/`、`ios/` 生成物不提交。

| 场景 | 自动化覆盖 | Android/iOS 平台验收 |
| --- | --- | --- |
| 来源和完整性 | 五类来源、续页边界/重复/失败、部分内容、过期会话 | 真正长回答、无描述问题、无正文/删除/权限受限内容 |
| 序列化 | 标题/列表/嵌套/表格/脚注/公式、未知结构、URL 脱敏 | 外部 Markdown 阅读器、中文换行、宽表格与复杂公式 |
| 图片资源 | 去重、全部语义位置、内嵌图、无凭据下载、超限/超时/取消 | 弱网、缺图重试、离线打开 HTML 与 Markdown ZIP |
| 文件与身份 | 路径约束、ZIP 资产引用、迟到写入清理、会话切换 | 空间不足、退出/后台、文件提供者行为 |
| PDF | 只打印静态嵌入资源、临时文件与取消结果清理 | A4 分页、表头重复、首尾页、图片/公式就绪与裁切 |
| 长图 | 连续分段、PNG 像素及顺序保真、自动合并与超长分组、无效 PNG/解码上限/取消 | 不同 DPI、实际拼接边界、超长正文、嵌入图片/公式、后台/旋转/取消 |
| 保存与分享 | SAF 取消/迟到创建清理、全部图片保存、单 ZIP 分享 | Android SAF、iOS“存储到文件”、相册拒绝权限与部分失败 |

Jest 中的原生模块使用替身，不能确认实际 PDF、图片像素或外部保存结果。交付时须单独列出已执行的命令、prebuild 结果和未完成的设备验证，不将预览通过或单元测试通过表述为原生平台验收完成。
